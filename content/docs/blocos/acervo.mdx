Antes deste design system, o Supernova já publicava componentes prontos em três repositórios. Esta página lista o que existe lá, lido de instantâneos com data em `data/acervo/`, e dá o comando de instalação de cada item. O código continua onde nasceu: nada foi copiado para cá, e cada comando aponta para o registry de origem.

<Callout title="Proveniência">
  Os blocos são adaptados de shadcn/studio (MIT + Commons Clause); a cláusula
  restringe vender ou redistribuir os componentes em si e está registrada como
  pendência de revisão jurídica. Os efeitos são originais de David Haz (Canvas
  UI, MIT + Commons Clause), distribuídos pelo Supernova Shadcn. Os layouts são
  código do Supernova sob MIT.
</Callout>

## Como atualizar

Os instantâneos são cópias dos arquivos gerados pelos repositórios de origem; a data está em `data/acervo/README.md`. Para atualizar, copie os arquivos de novo. Nunca edite os JSON à mão: as contagens desta página saem deles.
