Um bloco é uma página inteira ou uma composição de vários componentes, pronta para adaptar. Cada bloco tem prévia em tela cheia, comando de instalação, lista de arquivos e a nota do que mudou ao entrar no LAB / DESIGN.

<BlocksList />

## Origem

Os blocos partem de pacotes exportados do `shadcn-examples`, cujo código base é o shadcn/ui (MIT). Ao entrar no LAB / DESIGN, cada bloco passa a usar os componentes do LAB / DESIGN onde eles existem (Button, Badge, Input), ícones lucide, textos em pt-BR e nenhuma imagem externa. A licença do repositório de origem fica registrada como "a confirmar" até ser lida.
