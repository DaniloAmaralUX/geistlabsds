## Props

| Prop         | Tipo                                                          | Padrão      |
| ------------ | ------------------------------------------------------------- | ----------- |
| `color`      | `"gray" \| "blue" \| "green" \| "red" \| "amber" \| "violet"` | `"gray"`    |
| `appearance` | `"solid" \| "subtle"`                                         | `"solid"`   |
| `size`       | `"sm" \| "md" \| "lg"`                                        | `"md"`      |
| `shape`      | `"default" \| "pill"`                                         | `"default"` |
| `asChild`    | `boolean`                                                     | `false`     |

## Acessibilidade

O badge é texto; a cor nunca é a única informação. Combine com a palavra ou o ícone certo.

## Notas de implementação

- A pílula é a prop `shape`, não um componente à parte.
- Não há variante de contraste nem ícone à direita. Entram quando houver caso de uso.
