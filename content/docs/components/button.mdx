## Intenções

`primary` para a ação principal da tela, `secondary` para as demais, `tertiary` quando o botão não deve pesar. `error` e `warning` só para ações destrutivas ou arriscadas.

## Props

| Prop                | Tipo                                                             | Padrão      |
| ------------------- | ---------------------------------------------------------------- | ----------- |
| `variant`           | `"primary" \| "secondary" \| "tertiary" \| "error" \| "warning"` | `"primary"` |
| `size`              | `"sm" \| "md" \| "lg"`                                           | `"md"`      |
| `shape`             | `"default" \| "square" \| "circle"`                              | `"default"` |
| `loading`           | `boolean`                                                        | `false`     |
| `prefix` / `suffix` | `ReactNode`                                                      | —           |
| `asChild`           | `boolean`                                                        | `false`     |

Aceita todas as props de `button`.

## Acessibilidade

- Foco pelo teclado com anel de 2px e deslocamento, visível sobre qualquer fundo.
- `loading` aplica `aria-busy` e `disabled`; o indicador é `aria-hidden`.
- Botões só de ícone precisam de `aria-label`.
- As cores `error` e `warning` mantêm contraste AA com o texto.

## Notas de implementação

- `shape` cobre o botão só de ícone; não há prop separada para isso.
- Não há variantes com sombra nem variante fantasma. Entram quando houver caso de uso.
