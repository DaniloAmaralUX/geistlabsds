## Props

| Prop        | Tipo                     | Padrão             |
| ----------- | ------------------------ | ------------------ |
| `text`      | `string \| string[]`     | —                  |
| `prompt`    | `boolean`                | `true`             |
| `dark`      | `boolean`                | `false`            |
| `width`     | `string`                 | `100%`             |
| `onCopy`    | `(text: string) => void` | —                  |
| `copyLabel` | `string`                 | `"Copiar comando"` |

## Acessibilidade

- O botão tem `aria-label` e foco visível; o `$` é decorativo (`aria-hidden`).
- Ao copiar, uma região `aria-live` anuncia "Copiado".
- O texto é selecionável e rola horizontalmente quando não cabe.

## Diferenças em relação ao Geist

O Geist tem os tipos `success`, `error`, `warning` e `lite`. Aqui só `dark`; as cores por intenção ficam para quando houver uso.
