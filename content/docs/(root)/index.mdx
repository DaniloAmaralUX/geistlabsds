**LAB / DESIGN** é o lugar onde a equipe encontra fundamentos, componentes e código pronto para usar. Esta é a primeira entrega, a **POC 1**: o nosso Geist.

## O que é

- **Fundamentos**: cores, tipografia, espaçamento e raio, com os valores que o CSS realmente usa.
- **Componentes**: cada um com demonstração interativa, código e comando de instalação.
- **Cobertura**: a lista completa do Geist e o estado de cada item aqui.

A referência visual é o [Geist](https://vercel.com/geist/introduction), o design system da Vercel. O código é implementação própria sobre shadcn, Radix e Tailwind; nada é copiado da Vercel.

## O que está pronto nesta rodada

<Callout title="Escopo da POC 1">
  Fundações e cinco componentes ponta a ponta: Button, Badge, Input, Note e
  Snippet. Os demais itens do Geist estão inventariados na [página de
  cobertura](/docs/fundamentos/cobertura) e entram nas rodadas seguintes.
</Callout>

## Como usar

1. Instale o tema para receber as cores e o raio no seu projeto shadcn.
2. Instale os componentes que precisar, um a um.
3. Importe de `@/components/ui/<nome>`.

Veja a [instalação](/docs/installation) para os comandos.

## Para agentes

O site publica `llms.txt`, `llms-full.txt`, versões em Markdown de cada página (basta acrescentar `.md` à URL) e o índice do registry em `/r/registry.json`. O MCP oficial do shadcn lê este registry.
