As cores do LAB / DESIGN são definidas em OKLCH, que mantém a luminosidade perceptual constante entre matizes. Cada escala tem dez passos. No modo escuro a ordem inverte: o passo 100 é sempre o mais próximo do fundo e o 1000, o mais próximo do texto.

A coluna de contraste mostra a razão WCAG de cada passo sobre o fundo daquele modo. "AA" é 4,5:1 ou mais, o mínimo para texto normal. "AA grande" é 3:1 ou mais, suficiente para texto grande e ícones.

## Tokens semânticos

Os componentes não usam a escala diretamente. Usam tokens com nome de função, no vocabulário do shadcn, para que qualquer componente compatível com o ecossistema shadcn receba o mesmo visual. O tema instalável entrega exatamente estes valores.

## No código

No Tailwind, os dois níveis ficam disponíveis como classes:

- Escalas: `bg-ds-gray-100`, `text-ds-blue-700` e assim por diante.
- Tokens semânticos, no vocabulário do shadcn: `bg-background`, `text-muted-foreground`, `border-border`, `ring-ring`.

Para levar as cores ao seu projeto, instale o Tema LAB / DESIGN. Ele entra pelo CLI do shadcn e não adiciona dependência de runtime.
