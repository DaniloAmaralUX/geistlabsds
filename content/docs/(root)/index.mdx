**Supernova** é o design system do LAB / DESIGN. Reúne fundamentos, componentes, blocos e temas com prévia real e código que entra no seu projeto pelo CLI do shadcn. A implementação é própria, sobre shadcn, Radix e Tailwind, e é compatível com o ecossistema shadcn.

## O que existe hoje

- [Fundamentos](/docs/fundamentos): cores, tipografia, espaçamento e raio, lidos de `constants/tokens.ts`, o mesmo arquivo que gera o CSS do site e o tema instalável.
- [Componentes](/docs/components): cada um com prévia interativa, código, props, acessibilidade e comando de instalação.
- [Blocos](/docs/blocos): páginas e composições prontas, com prévia em tela cheia e instalação pelo shadcn.
- [Temas](/docs/temas): o tema do Supernova e os presets do Supernova Shadcn, para instalar, trocar ao vivo e ajustar no Theme Studio.
- [Acervo](/docs/blocos/acervo): blocos, layouts e efeitos que os repositórios do Supernova já publicam, com o comando de instalação de cada item.
- [Roteiro](/docs/fundamentos/roteiro): os componentes previstos e o estado de cada um. Os totais derivam do roteiro; nenhum número é escrito à mão.

<Callout title="Estado atual">
  A primeira rodada entregou os fundamentos e os primeiros componentes ponta a
  ponta. O [roteiro](/docs/fundamentos/roteiro) mostra o que está publicado, o
  que está em adaptação e o que ainda só consta na lista.
</Callout>

## Como usar

1. Instale o tema para receber as cores e o raio no seu projeto shadcn.
2. Instale os componentes e os blocos que precisar, um a um.
3. Importe de `@/components/ui/<nome>`.

Veja a [instalação](/docs/installation) para os comandos. Cada bloco traz o próprio comando na sua página.

## Para agentes

O site publica `llms.txt`, `llms-full.txt`, versões em Markdown de cada página (acrescente `.md` à URL) e o índice do registry em `/r/registry.json`. O MCP oficial do shadcn lê esse registry. O texto é o mesmo para pessoas e agentes.

A origem dos blocos, dos temas e do acervo está registrada na página de cada um. O shadcn e a Vercel não participam deste projeto.
