Os fundamentos são a parte do LAB / DESIGN que todo componente herda. Vivem em um só arquivo, `constants/tokens.ts`, que gera o CSS do site e o tema instalável. Estas páginas leem esse arquivo em vez de repetir os valores à mão: o que você vê aqui é o que o CSS entrega.

## Princípios

- **Neutro por padrão.** Superfícies e texto em cinza puro. Cor só quando comunica intenção: azul para ação, vermelho para erro, âmbar para aviso, verde para sucesso, violeta para destaque.
- **Uma escala, dois modos.** Cada cor tem dez passos, de 100 a 1000. No modo escuro a escala inverte, então `gray-100` é sempre o passo mais próximo do fundo.
- **Raio de 6px.** Botões e campos usam o raio base. Cards e notas ficam um passo acima. Pílulas são redondas.
- **Foco visível.** Todo elemento interativo mostra um anel azul de 2px ao receber foco pelo teclado.
- **Tipografia acoplada.** Cada papel tipográfico fixa tamanho, entrelinha, peso e tracking juntos. Não ajuste um sem revisar os outros.
