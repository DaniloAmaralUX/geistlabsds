## Props

| Prop                | Tipo                   | Padrão |
| ------------------- | ---------------------- | ------ |
| `label`             | `ReactNode`            | —      |
| `description`       | `ReactNode`            | —      |
| `error`             | `ReactNode`            | —      |
| `prefix` / `suffix` | `ReactNode`            | —      |
| `size`              | `"sm" \| "md" \| "lg"` | `"md"` |
| `wrapperClassName`  | `string`               | —      |

Aceita todas as props de `input`, exceto `size` (que aqui é o tamanho visual).

## Acessibilidade

- `label` vira `<label for>` ligado ao campo por `id` gerado.
- `description` e `error` entram em `aria-describedby`.
- `error` ativa `aria-invalid`.
- Foco pelo teclado com anel de 2px no contêiner.

## Notas de implementação

- `size` é o tamanho visual; a prop nativa de mesmo nome não é repassada.
- Não há variantes de busca nem botão de limpar o campo. Estão previstas no [roteiro](/docs/fundamentos/roteiro).
