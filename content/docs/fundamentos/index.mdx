Os fundamentos são a parte do design system que todo componente herda. Vivem em um só arquivo, `constants/tokens.ts`, que gera o CSS do site e o tema instalável. O que aparece nestas páginas é lido desse arquivo, não escrito à mão.

## Princípios

- **Neutro por padrão.** Superfícies e texto em cinza puro; cor só quando comunica intenção: azul para ação, vermelho para erro, âmbar para aviso, verde para sucesso, violeta para destaque.
- **Uma escala, dois modos.** Cada cor tem dez passos, de 100 a 1000. No escuro a escala inverte, então `gray-100` é sempre "o mais próximo do fundo".
- **Raio de 6px.** Botões e campos usam o raio base; cards e notas um passo acima; pílulas são redondas.
- **Foco visível.** Todo elemento interativo mostra um anel azul de 2px ao receber foco pelo teclado.
- **Tipografia acoplada.** Cada papel tipográfico fixa tamanho, entrelinha, peso e tracking juntos. Não se ajusta um sem o outro.
