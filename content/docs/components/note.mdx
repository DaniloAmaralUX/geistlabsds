## Rótulo

O rótulo padrão segue o tipo ("Nota:", "Sucesso:", "Erro:", "Aviso:"). Passe outro texto ou `false` para remover.

## Props

| Prop     | Tipo                                                                        | Padrão         |
| -------- | --------------------------------------------------------------------------- | -------------- |
| `type`   | `"default" \| "secondary" \| "success" \| "error" \| "warning" \| "violet"` | `"default"`    |
| `label`  | `ReactNode \| false`                                                        | rótulo do tipo |
| `fill`   | `boolean`                                                                   | `false`        |
| `action` | `ReactNode`                                                                 | —              |
| `size`   | `"sm" \| "md" \| "lg"`                                                      | `"md"`         |

## Acessibilidade

- `error` e `warning` usam `role="alert"` e são anunciados ao aparecer.
- `success` usa `role="status"`; os demais, `role="note"`.
- A cor acompanha o rótulo; a mensagem nunca depende só dela.

## Diferenças em relação ao Geist

Mesmos tipos e a mesma prop `fill`. O Geist tem `disabled`; aqui não há caso de uso ainda.
